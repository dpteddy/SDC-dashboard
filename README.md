# SDC Dashboard

Dashboard for visualizing occupancy data in the SDC building.

## Setup

1. Install Anaconda (https://www.anaconda.com/download/success?reg=skipped)

2. Create the environment
(conda env create -f environment.yml)

3. Activate the environment
(conda activate SDC_plotly_310)

4. Run the dashboard
(python dashboard.py)

## Open the dashboard

Go to:
http://127.0.0.1:8050
